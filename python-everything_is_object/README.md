# Python - Everything is Object

Answers exploring how Python treats everything as an object: object types,
identity vs equality, mutable vs immutable objects, references, aliasing,
and how arguments are passed to functions.

| `1-answer.txt` | Function to get an object's identifier |
| `2-5-answer.txt` | Object identity for integers |
| `6-9-answer.txt` | Equality vs identity for strings |
| `10-13-answer.txt` | Equality vs identity for lists |
| `14-18-answer.txt` | Mutability and passing arguments to functions |

| `20-26-answer.txt` | Tuples and their identity |
| `27-28-answer.txt` | Rebinding vs in-place modification and `id()` |
