# Python - More Classes and Objects

This directory builds a `Rectangle` class step by step, covering properties,
magic methods, class attributes, static methods, and class methods.

## Files

| File | Description |
|------|-------------|
| `0-rectangle.py` | Empty `Rectangle` class |
| `1-rectangle.py` | `width` and `height` properties with validation |
| `2-rectangle.py` | Adds `area()` and `perimeter()` |
| `3-rectangle.py` | Adds `__str__` to draw the rectangle with `#` |
| `4-rectangle.py` | Adds `__repr__` for use with `eval()` |
| `5-rectangle.py` | Adds `__del__` printing "Bye rectangle..." |
| `6-rectangle.py` | Adds `number_of_instances` class attribute |
| `7-rectangle.py` | Adds customizable `print_symbol` class attribute |
| `8-rectangle.py` | Adds `bigger_or_equal()` static method |
| `9-rectangle.py` | Adds `square()` class method |

## Requirements

- Python 3
- No external modules are imported
- All files are executable and PEP8-compliant
