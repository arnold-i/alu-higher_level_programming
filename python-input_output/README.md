# Python - Input/Output

Exercises on reading and writing files, JSON serialization and
deserialization, and object persistence, plus a Pascal's triangle
interview-prep function.

## Files

| File | Description |
|------|-------------|
| `0-read_file.py` | Read a UTF-8 file and print it |
| `1-write_file.py` | Write a string to a file, return char count |
| `2-append_write.py` | Append a string to a file, return char count |
| `3-to_json_string.py` | Object to JSON string |
| `4-from_json_string.py` | JSON string to object |
| `5-save_to_json_file.py` | Save an object to a JSON file |
| `6-load_from_json_file.py` | Load an object from a JSON file |
| `7-add_item.py` | Add CLI args to a list saved in `add_item.json` |
| `8-class_to_json.py` | Dictionary description of a class instance |
| `9-student.py` | `Student` with `to_json()` |
| `10-student.py` | `Student` with attribute-filtered `to_json()` |
| `11-student.py` | `Student` with `reload_from_json()` |
| `12-pascal_triangle.py` | Pascal's triangle of n rows |

## Requirements

- Python 3
- All file operations use the `with` statement
- All files are executable and PEP8-compliant
