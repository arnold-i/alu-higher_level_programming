The ``1-my_list`` module
========================

Using ``MyList``
----------------

Import the class:

    >>> MyList = __import__('1-my_list').MyList

An empty MyList prints as an empty list:

    >>> my_list = MyList()
    >>> print(my_list)
    []
    >>> my_list.print_sorted()
    []

A populated MyList keeps its own order, print_sorted shows a sorted copy:

    >>> my_list = MyList()
    >>> my_list.append(1)
    >>> my_list.append(4)
    >>> my_list.append(2)
    >>> my_list.append(3)
    >>> my_list.append(5)
    >>> print(my_list)
    [1, 4, 2, 3, 5]
    >>> my_list.print_sorted()
    [1, 2, 3, 4, 5]
    >>> print(my_list)
    [1, 4, 2, 3, 5]

It also works with negative numbers:

    >>> my_list = MyList()
    >>> my_list.append(3)
    >>> my_list.append(-3)
    >>> my_list.append(0)
    >>> my_list.print_sorted()
    [-3, 0, 3]

A single-element list is unchanged:

    >>> my_list = MyList()
    >>> my_list.append(42)
    >>> my_list.print_sorted()
    [42]
