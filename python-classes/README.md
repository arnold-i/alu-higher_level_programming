# Python - Classes and Objects

This directory contains exercises on Python classes and object-oriented
programming, building a `Square` class step by step.

## Files

| File | Description |
|------|-------------|
| `0-square.py` | Empty `Square` class |
| `1-square.py` | `Square` with a private `size` attribute |
| `2-square.py` | `Square` with size type/value validation |
| `3-square.py` | Adds a public `area()` method |
| `4-square.py` | Adds a `size` getter and setter (property) |
| `5-square.py` | Adds `my_print()` to draw the square with `#` |
| `6-square.py` | Adds a `position` attribute used by `my_print()` |

## Requirements

- Python 3
- No external modules are imported
- All files are executable
